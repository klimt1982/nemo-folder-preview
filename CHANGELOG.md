# Changelog

## 0.1.0 — 2026-09-25

First release of Nemo Folder Preview, a Linux Mint Cinnamon-focused fork of
Cover Thumbnailer.

- Replaces legacy music and generic-folder previews with photo-folder previews.
- Shows one to four images inside Mint-Y folder icons.
- Supports WebP and other Pillow-compatible image formats.
- Uses the active Mint-Y theme automatically or a selected Mint-Y variant.
- Adds Spanish and English interface options, plus light, dark and system themes.
- Uses the Nemo Folder Preview command, configuration and installation namespace.
- Generates previews at the image size requested by Nemo for sharp large icons.
- Adds integration tests for mosaics, WebP and requested thumbnail sizes.
- Ensures installed desktop integration and shared assets have readable permissions.

## Upstream base

Nemo Folder Preview is based on Cover Thumbnailer 0.10.3 by Fabien Loison,
released under the GNU GPL v3 or later.
